# SPD Lab 4.0 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the existing SPD Lab v3.3.8 modifications on top of official Shattered Pixel Dungeon v4.0.0 without modifying the preserved `master` branch.

**Architecture:** Treat official v4.0.0 as authoritative. Copy Lab-only classes/assets unchanged where possible, then reapply the smallest Lab-specific deltas to shared upstream files. Build failures are used as compatibility tests for API drift, and fixes must preserve v4.0 behavior rather than restoring old 3.3.8 implementations.

**Tech Stack:** Java 11 source compatibility, Gradle/Android Gradle Plugin 9.2.0, Android SDK 36, libGDX 1.14.0, GitHub Actions Java 21 build environment.

**Spec:** `docs/superpowers/specs/2026-09-15-spdlab-4.0-port-design.md`

## Global Constraints

- Base branch content remains official v4.0.0 commit `2bb34a4e91d29c8785a9363cad6ddfe5122b1d4f` plus Lab port commits.
- Do not modify or rewrite `master`.
- Keep app name `녹픽던 실험실`.
- Keep package `com.solji.spdlab` so the Lab app can coexist with official Shattered Pixel Dungeon.
- Keep v4.0 build-system changes, including Android Gradle Plugin 9.2.0 and Android SDK 36.
- Use a Lab version string based on `4.0.0`, beginning with `4.0.0-lab-port1`.
- Do not overwrite shared v4.0 files with their v3.3.8 versions.
- Existing v3.3.8 Lab save compatibility is not a requirement for the first port.
